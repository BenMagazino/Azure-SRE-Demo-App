# Security Policy

## Supported versions

Security fixes are made on a best-effort basis for the latest commit on `main` and the latest
published GitHub Release. Older releases may not receive fixes.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, pull request, or other
public channel.

Use this repository's **Security** tab and select **Report a vulnerability** to submit a private
vulnerability report:

<https://github.com/BenMagazino/Azure-SRE-Demo-App/security/advisories/new>

Include the affected version or commit, reproduction steps, impact, and any suggested mitigation.
The repository owner will review reports and coordinate disclosure on a best-effort basis. No
response or remediation SLA is offered.

This is an independent personal project. It is not owned, approved, endorsed, or supported by
Microsoft. Reports about this repository should not be sent to the Microsoft Security Response
Center. Vulnerabilities in an Azure product or Microsoft service should instead be reported through
the applicable official Microsoft security channel.
