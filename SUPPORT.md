# Support

Support for this project is provided by the community on a best-effort basis through
[GitHub Issues](https://github.com/BenMagazino/Azure-SRE-Demo-App/issues). Search existing issues
before opening a new one, and include the application version, relevant logs with secrets removed,
and steps to reproduce the problem.

There is no service-level agreement, guaranteed response time, or guaranteed fix. Support for this
personal repository is not provided by Microsoft Customer Service and Support (CSS), Microsoft
Unified Support, or any other Microsoft support agreement.

For problems with Azure products, Azure service availability, subscriptions, billing, quotas, or
production resources, use the applicable
[official Microsoft support channel](https://azure.microsoft.com/support/options/). Do not include
credentials, access tokens, device codes, or other secrets in a GitHub issue.

Security vulnerabilities must be reported privately as described in [SECURITY.md](SECURITY.md), not
through a public issue.
